# 课表转日历

把西北工业大学教务系统的《学生课表》PDF，转成可以导入 iPhone / iPad / Mac / Android
日历的 `.ics` 文件，并自动加上两类提醒：

1. **每节课提前 N 分钟提醒**（默认 20 分钟）
2. **每晚固定时间汇总第二天要上的课**（默认 22:00）

双击 `TimetableToCalendar.exe` 即可运行。

---

## 怎么用

1. 双击 `TimetableToCalendar.exe`（首次启动约 2-3 秒）
2. 「课表 PDF」选你的课表（如果同目录有 `sample-timetable.pdf`，可以先拿它试）
3. **确认「第 1 周周一」的日期** —— 这一步最关键，见下文
4. 点右下角「解析课表」
5. 对着预览表核对一遍（有错的直接双击那一行改）
6. 点「生成 .ics」

快捷键：`F5` 解析、`Ctrl+S` 生成、`Ctrl+O` 选择文件。

## 导进 iPhone

1. **邮件**（最省事）：把 `.ics` 当附件发到自己邮箱 → iPhone 打开邮件 → 点附件 →
   「添加到日历」→「全部添加」
2. **AirDrop**（Mac）：隔空投送到 iPhone，用「日历」打开
3. **文件 App**：存进 iCloud Drive，iPhone 上点开 → 共享 → 日历

> 建议先新建一个叫「课表」的日历再导入，以后不想要了删掉这一个日历就干净了。

---

## 每个学期要改的两件事

程序与学期无关（周次 → 日期、循环日程、提醒都是推出来的），但有两项**必须每学期手工更新**：

| 要改的 | 在哪改 | 怎么确认 |
|---|---|---|
| **第 1 周周一** | 界面顶部「第 1 周周一」 | 看校历上「X月X日 20XX级本科生开课」那一行 |
| **本学期节假日安排** | 「载入节假日文件…」 | 看当年国务院通知 + 学校教务处调课通知 |

节假日文件是纯文本，界面上有「导出模板」可以直接生成：

```
放假 2027-04-04 2027-04-06 清明节
放假 2027-05-01 2027-05-05 劳动节
调休 2027-04-25
```

省略「执行星期几」= 那天照常执行当天星期几的课表（高校通行做法）；
写成 `调休 2027-04-25 周一` 就是那天补周一的课。

**程序会主动拦住「忘记更新」**：内置的配置自检会检查

- 第 1 周周一不是周一 → 报错
- **填的日期推出来的学期和 PDF 里写的学期对不上**（例如 PDF 是「2026-2027 秋」但你填的
  日期推出「2026-2027 春」）→ 报错。这条专治「下学期忘了改日期」
- **节假日预设全部落在本学期范围之外** → 报错。这条专治「下学期沿用了上学期的节假日」
- 课程用到的节次没设时间 → 报错

## 解析结果一定要扫一眼

PDF 里的文字是「版面还原」出来的，绝大多数情况没问题，但**教室和教师是靠空格分隔识别的**，
个别行可能把教师并进教室名（例如显示成「实验大楼C座5楼向礼琴」）。双击那一行改一下即可。

程序内置两项自检，解析完直接打在日志里：

- **时间冲突检测**：同一天同一时段不应该有两门不同的课。真实课表必然无冲突，
  所以一旦报冲突，几乎一定是解析串行了，请重点核对
- **解析失败条目**：某门课没解析出周次/节次时会明确列出来，不会静默丢掉

## 命令行用法

```powershell
TimetableToCalendar.exe --cli 课表.pdf -o 我的课表.ics        # 命令行转换
TimetableToCalendar.exe --selftest 课表.pdf out.ics 报告.txt   # 静默自检（写报告文件）
```

## 适用范围

- **能复用**：同一所学校、教务系统导出格式不变的前提下，往后每个学期都能用。
- **不适用**：换学校 / 换教务系统 / 学校改了课表导出格式。这种情况下程序会**明确报错退出**
  （「没有找到星期一…星期日表头」），不会硬猜出一个错误结果。
- **作息时间调整**：界面里可以选预设，也可以点「节次时间…」手动改。

## 界面

- 圆角控件用 **Pillow 4 倍超采样渲染再降采样**，边缘平滑无锯齿
  （tkinter 自带的 Canvas 没有抗锯齿，直接画圆弧一定是锯齿边）
- 圆角渲染把「形状覆盖度」和「颜色」分开处理，避免透明区的黑色渗进边缘形成暗角
- 程序声明了 **DPI 感知**，在高分屏上按真实分辨率原生渲染，字体清晰
- 窗口尺寸会自动限制在屏幕可用范围内，小屏笔记本上也不会超出屏幕
- 窗口可以**自由缩放**（竖直方向也一样）：拉高时课程预览表跟着变高，压矮到装不下时
  中间内容区出现纵向滚动条，顶栏和底部操作栏始终固定在窗口上；滚轮在预览表 / 日志里
  滚它们自己，在别处翻整页
