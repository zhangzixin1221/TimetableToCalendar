# 使用说明 —— 单文件安装包

**交付物：`TimetableToCalendar-Setup.exe`（27.8 MB）**

双击运行 → 选安装位置 → 解压安装。就这一个文件，分发给别人也只用给这一个。

> **落盘的东西一律用英文路径**（中文路径在工具链、备份脚本、云同步里容易出问题），
> 界面文字仍然是中文：安装目录 `TimetableToCalendar\`、主程序 `TimetableToCalendar.exe`、
> 卸载器 `Uninstall.exe`、示例课表 `sample-timetable.pdf`、快捷方式 `TimetableToCalendar.lnk`。

---

## 为什么做成安装包

应用本体是 81.3 MB / 968 个文件（PyInstaller 的 onedir 形态），直接当"免安装版"分发有
两个麻烦：整个文件夹必须一起拷贝，而且不方便传给别人。

安装包把这份文件夹用 **7-Zip 的 LZMA2 最高压缩**到 26.5 MB（压缩率 3.06 倍），再连同
解压内核一起内嵌进**一个** exe。装完之后是解压好的目录，所以启动快（不用每次解压到临时目录）。

| | 大小 |
|---|---|
| 应用本体（未压缩） | 81.3 MB |
| **安装包（本产物）** | **27.8 MB** |
| 安装后占用磁盘 | 约 81.3 MB |

## 用法

**图形界面**：双击 `TimetableToCalendar-Setup.exe` → 选安装位置
（默认 `D:\Tools\TimetableToCalendar`；没有 D 盘时用
`%LOCALAPPDATA%\Programs\TimetableToCalendar`）
→ 可勾选桌面/开始菜单快捷方式 → 点「立即安装」。

**安装位置会自动新建以项目名命名的子目录**：你只要选到父目录就行，安装器会自己补一层
`TimetableToCalendar`，输入框里也会立刻回填成最终位置给你确认。

| 你填 / 选的 | 实际装到 |
|---|---|
| `D:\Tools` | `D:\Tools\TimetableToCalendar` |
| `D:\Tools\` | `D:\Tools\TimetableToCalendar` |
| `D:\` | `D:\TimetableToCalendar` |
| `C:\Program Files` | `C:\Program Files\TimetableToCalendar` |
| `D:\Tools\TimetableToCalendar` | 原样（重复安装 / 升级不会再套一层） |

如果父目录是安装时新建的，卸载时它空了会被一并删掉，不留空文件夹。

**命令行**：

```powershell
TimetableToCalendar-Setup.exe --silent --dir="D:\Tools"                    # 静默安装到 D:\Tools\TimetableToCalendar
TimetableToCalendar-Setup.exe --silent --dir="D:\Tools\TimetableToCalendar" # 同上（两种写法结果一致）
TimetableToCalendar-Setup.exe --uninstall                                  # 卸载（弹确认）
TimetableToCalendar-Setup.exe --uninstall --silent                         # 静默卸载
TimetableToCalendar-Setup.exe --uitest report.txt                          # 界面自检，结果写报告
TimetableToCalendar-Setup.exe --pathcheck report.txt                       # 安装位置规则自检，结果写报告
```

卸载也可以走「设置 → 应用 → 课表转日历」。

**不需要管理员权限**：全部写 `HKCU`（当前用户），装到默认位置也不需要提权。

**卸载会很干净**：卸载器先把自己复制到 `%TEMP%` 再执行删除，所以安装目录里没有任何
进程占用，目录能整个删掉（从「设置 → 应用」卸载时工作目录正是安装目录，老实现会因为
这个留下残留文件夹，现在已经修掉）。

## 安装包是怎么做的（不依赖第三方工具）

没有用 Inno Setup / NSIS —— 那些要额外安装。这里全部用系统自带的东西拼出来：

1. **应用本体**：`build_onedir.ps1` 用 PyInstaller 构建成 onedir 文件夹
2. **压缩**：用 7-Zip 的 LZMA2 最高压缩打成 `payload.7z`（26.6 MB）
3. **解压内核**：官方 7-Zip extra 包里的独立 `7za.exe`（1.2 MB）
4. **卸载器**：单独编译的小程序（**8 KB**，不内嵌载荷）
5. **安装器**：用 Windows 自带的 `csc.exe` 编译的 C# WinForms 程序，把上面三样
   一起内嵌为资源

> 一个踩过的坑：最初图省事，把「安装器自己」复制到安装目录当卸载器，结果安装后占用
> 从 81 MB 涨到 105 MB —— 因为安装器内含 27 MB 载荷。改成单独编译小卸载器后正常。

## 界面

与主程序统一：**圆角 + 纯色**，共用同一套调色板（深蓝标题带 `#101828` + 白色卡片 +
靛蓝主色 `#4F46E5`）。

- 圆角由 GDI+ 的 `GraphicsPath` 绘制 —— WinForms 有抗锯齿，所以圆角是平滑的
  （主程序用的是 tkinter，Canvas 没有抗锯齿，那边改用 Pillow 4 倍超采样渲染）
- 声明了 **DPI 感知**，高分屏下按真实分辨率原生渲染，字体清晰
- 所有像素尺寸按 DPI 比例缩放（`Theme.S()`），窗口客户区逻辑 560×420
- Windows 11 上还通过 `DwmSetWindowAttribute` 给窗口本身加了圆角
- 主程序窗口**可以自由缩放**（含竖直方向）：拉高时课程预览表跟着变高；压矮到装不下时
  中间内容区出现纵向滚动条，顶栏和底部操作栏始终固定在窗口上
- 左右缩放时**预览表的列宽会按比例自适应**（各列有各自的最小宽度），保证「教室 / 教师」
  这类右边的列不会被裁掉；实在塞不下才出现横向滚动条

## 重新构建

```powershell
# 1) 先构建应用本体（中间产物，输出到上一级 TimetableToCalendar\）
powershell -ExecutionPolicy Bypass -File build_onedir.ps1
# 2) 再打包成安装包（输出到上一级 TimetableToCalendar-Setup.exe；-Clean 会顺手删掉中间产物）
powershell -ExecutionPolicy Bypass -File build_installer.ps1 -Clean
```

**交付形态只有安装包这个文件**，构建时产生的 `TimetableToCalendar\` 目录只是安装包的载荷来源，
打完包就删掉了。

两个 `.ps1` 都必须保持 **UTF-8 带 BOM**，否则 Windows PowerShell 5.1 会按 GBK 解析
中文导致语法错误（这个坑踩过）。注意：用编辑器/工具改这两个文件后要确认 BOM 还在。

## 两点说明

- **没有代码签名**，所以首次运行会弹 SmartScreen「Windows 已保护你的电脑」，
  需要点「更多信息」→「仍要运行」。要对公分发就需要买代码签名证书。
- **安装位置建议留在 `D:\Tools`** 这类用户目录。如果手动改成 `C:\Program Files`，
  因为程序写的是 HKCU 且解压需要写权限，非管理员账户可能会失败。
- 从「设置 → 应用」卸载时，列表里显示的名字仍是中文「课表转日历」（这是显示名，
  不是路径）；注册表键名和磁盘路径都是英文。
